Coverage is below the project's 100% goal.
Remaining gaps include allocation/synchronization failures, many invalid-argument combinations, TLS-specific uProtocol paths and some optional attributes.
No claim is made that all branches or all pinned specification requirements are verified.
The explicit-zero TTL ambiguity between the pinned mapping and MQTT expiry semantics is documented in `README.adoc` for maintainer discussion; omit TTL for non-expiring publish/notification messages.

Not performed: embedded-board execution, Windows builds, actual big-endian execution, independent-uProtocol-library interoperability, MISRA static analysis, or the complete repository-wide CI selection.
A complete uProtocol language SDK, services and RPC convenience layer are outside this transport addon's scope, as described in `README.adoc`.

== Reproduction

Use the normal `scripts/build_mqtt.sh` / `scripts/test_mqtt.sh` wrappers for the nine profiles.
To enable the optional broker test in an existing default build:

[source,sh]
----
cmake -S test/cmake/mqtt -B test/cmake/mqtt/build/default_build_coverage -DNXD_UPROTOCOL_BROKER_TESTS=ON
cmake --build test/cmake/mqtt/build/default_build_coverage -j 6
ctest --test-dir test/cmake/mqtt/build/default_build_coverage --output-on-failure
----

For this GCC 15 host, add the local warning exception when configuring each profile, for example `-DCMAKE_C_FLAGS_DEFAULT_BUILD_COVERAGE=-Wno-error=unterminated-string-initialization`.
The ThreadX Linux simulator required execution outside the agent sandbox; sandboxed runs terminated with SIGSYS.

Generated build/test logs, the sanitizer harness and coverage reports are in the ignored `build/uprotocol-reference/` directory on this workspace.
They are not source dependencies.
